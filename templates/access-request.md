# ข้อความขอสิทธิ์ผู้ตรวจอิสระ

ส่งข้อความนี้ให้เจ้าของ repo / owner ขององค์กร เพื่อขอสิทธิ์ที่จำเป็น
สิทธิ์ทั้งหมดที่ขอคือ **Read** เท่านั้น

---

สวัสดีครับ

ผมขอสิทธิ์เข้าถึงระดับ **Read** บน `<ORG>/<REPO>` ด้วยบัญชี GitHub **@MKOL-prog**
เพื่อทำหน้าที่ผู้ตรวจอิสระของ PR ครับ

**สิ่งที่ขอ**

1. เพิ่ม `@MKOL-prog` เข้าองค์กรในฐานะ Member (ไม่ใช่ Owner)
2. สร้างทีม `independent-auditors` และให้ทีมนี้สิทธิ์ **Read** บน repo
3. ติดตั้ง workflow `independent-audit-gate.yml` และ ruleset ตามเอกสาร SETUP

**สิ่งที่ผมทำไม่ได้ด้วยสิทธิ์นี้** — push, merge, แก้โค้ด, แก้ ruleset,
เปลี่ยนสิทธิ์ของใคร หรือเข้าถึง secret ขององค์กร ข้อจำกัดพวกนี้บังคับที่ระดับสิทธิ์ GitHub
ไม่ใช่แค่ข้อตกลง

**สิ่งที่ผมจะทำ** — อ่าน diff ของแต่ละ PR ตามเกณฑ์ในเอกสาร AUDIT-CHECKLIST
แล้วส่งรีวิว Approve / Request changes พร้อมเหตุผล การอนุมัติจะผูกกับ commit
ที่ตรวจจริง ถ้ามี push ใหม่หลังจากนั้น การอนุมัติจะหมดอายุและต้องตรวจใหม่

**เรื่องที่อยากให้ตัดสินใจไว้ก่อน**

- ให้ตรวจทุก PR หรือเฉพาะที่แตะพื้นที่ไหน
- เวลาตอบกลับที่คาดหวังต่อ PR หนึ่งอัน
- ถ้าผมไม่ว่างหรือต้องถอนตัวเพราะมีส่วนได้เสีย ใครเป็นผู้ตรวจสำรอง
- ถ้าจำเป็นต้องข้ามด่านในกรณีฉุกเฉิน ใครอนุมัติและบันทึกไว้ที่ไหน

เอกสารทั้งชุดอยู่ที่ `<ลิงก์ repo ชุดตรวจ>` ครับ
