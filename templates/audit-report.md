## ข้อสังเกต

| # | ระดับ | ไฟล์:บรรทัด | เรื่อง | ต้องแก้ก่อน merge |

| 1 | สูง / กลาง / ต่ำ | `path/file.ts:42` | | ใช่ / ไม่ |
| 2 | | | | |

**ระดับความรุนแรง**
- **สูง** — ข้อบกพร่องที่ทำให้ทำงานผิด ช่องโหว่ด้านความปลอดภัย หรือข้อมูลเสียหาย
- **กลาง** — เคสขอบที่ยังไม่ถูกจัดการ หลักฐานไม่พอ หรือความเสี่ยงตอนนำขึ้นระบบ
- **ต่ำ** — ข้อเสนอแนะ ไม่บล็อกการ merge
